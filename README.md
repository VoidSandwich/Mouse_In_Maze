# Mouse in a Maze (Q-Learning Simulation)

**Mouse in a Maze** — это интерактивное десктопное приложение на базе Java 21 (Swing/AWT), предназначенное для моделирования, обучения и анализа агента (мыши) в динамической среде с помощью обучения с подкреплением (Q-Learning). Программа воспроизводит процесс поиска оптимального пути в лабиринте с учетом промежуточных ресурсов (воды) и опасных зон (ловушек/тока).

## Основные функции
- **Генерация лабиринта (DFS):** Автоматическое создание идеального связного лабиринта алгоритмом поиска в глубину с гарантией наличия ровно одного пути между любыми клетками.
- **Интеллектуальное обучение (Q-Learning):** Классический табличный Q-learning с одношаговым TD(0)-обновлением, динамической системой наград и автоматическим затуханием исследовательского коэффициента ($\varepsilon$).
- **Валидация среды:** Проверка выполнимости задачи алгоритмом BFS до начала обучения (гарантия существования пути через воду к сыру).
- **Неоновая визуализация:** Плавный рендеринг игрового поля, стен, объектов среды и динамических шлейфов посещений агента на базе Java2D.
- **Сохранение и загрузка:** Сериализация и десериализация обученных моделей, лабиринтов и Q-таблиц в формат JSON без использования сторонних внешних библиотек.
- **Многопоточность:** Выполнение итераций обучения в фоновых потоках с помощью `SwingWorker`, обеспечивающее отзывчивость интерфейса и обновление статистики в реальном времени.

## Используемые механики и архитектура кода
- **Табличное обучение TD(0):** Агент накапливает матрицу оценок качества «действие в состоянии» $Q(s,a)$ и корректирует их по правилу Беллмана с учетом параметров $\alpha$ (скорость обучения) и $\gamma$ (дисконтирование).
- **Стратегия $\varepsilon$-greedy:** Плавный переход от случайного исследования среды к детерминированному выбору оптимальной политики по мере роста числа эпох.
- **Управление ресурсами и ограничениями:** Штрафы за столкновение со стенами, анти-фарм система для повторного входа в воду, ограничение длины эпизода и учет начального запаса энергии.
- **Инкапсуляция и чистота архитектуры:** Четкое разделение ответственности между классами логики среды (`Maze`, `MazeGenerator`), алгоритма обучения (`QLearningAgent`) и графического интерфейса (`MazeFrame`, `MazePanel`).
